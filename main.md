# Migration, Conflict & Geopolitical Narratives: A Data-Driven Comparative Framework

## Abstract
This project develops a reproducible computational framework for studying how migration is framed in geopolitical conflict contexts. It integrates displacement indicators, conflict-event measures, and news narratives across comparative case studies. The framework combines interpretable dictionary-based frame detection with temporal and actor-level analysis. Because the repository includes synthetic demonstration data, no empirical claim is made until the pipeline is executed on appropriately sourced real data.

## 1. Introduction
Migration during armed conflict is simultaneously a humanitarian issue and a geopolitical question involving borders, security, diplomacy, responsibility-sharing, and international institutions. Computational analysis can make changes in narrative emphasis measurable while retaining a transparent connection to source documents.

## 2. Research Questions
- How do geopolitical frames vary across crisis cases?
- How does framing change with conflict intensity and displacement?
- Which actors co-occur most often in migration-related narratives?

## 3. Data and Methods
The planned data architecture combines UNHCR displacement indicators, World Bank migration indicators, GDELT news data, and—where authorized—ACLED conflict-event data. Text is cleaned and scored against interpretable frame dictionaries. Temporal aggregation and actor co-occurrence provide comparative views.

## 5. Discussion
The framework is designed to test whether humanitarian, security, economic, responsibility, and diplomatic frames differ systematically across geopolitical crises. Interpretation must account for media selection, language coverage, data revisions, and coding limitations.

## 6. Conclusion
A reproducible, source-documented workflow can connect migration statistics, conflict events, and political narratives in a single analytical design. The next stage is real-data collection, annotation-based validation, robustness checks, and qualitative case verification.

## Reproducibility statement
Configuration, code, tests, data-fetching adapters, and documentation are included in this repository. External data are not redistributed where licenses or access conditions prohibit it.
