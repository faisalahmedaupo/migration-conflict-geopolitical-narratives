# Data dictionary

| Field | Meaning |
|---|---|
| date | observation date/year |
| case | comparative case label |
| country | country associated with observation |
| text | article/event narrative text |
| source | publisher/provider |
| actor | normalized actor name when available |
| event_type | conflict/event category |
| fatalities | reported fatalities when available |
| refugees | refugee population/count when available |
| displaced | displaced population/count when available |
| frame_* | binary frame indicators |

Provider-specific columns should be preserved in raw data and documented before transformation.
