# Research protocol

## Pre-registration-style checklist
- [ ] Finalize cases before inspecting outcome patterns.
- [ ] Define inclusion/exclusion criteria for news documents.
- [ ] Record languages and publishers covered.
- [ ] Freeze frame dictionary before final comparison, or clearly label post-hoc changes.
- [ ] Create a manually annotated validation sample.
- [ ] Report precision/recall/F1 for the frame classifier.
- [ ] Run sensitivity analyses with alternative dictionaries/weights.
- [ ] Report missingness and source coverage.
- [ ] Keep exploratory and confirmatory claims separate.

## Minimum credible empirical package
1. Real dataset provenance table.
2. Reproducible acquisition/preprocessing script.
3. At least one annotated validation set.
4. Classifier evaluation metrics.
5. Comparative figures.
6. Statistical/robustness analysis.
7. Qualitative interpretation with primary/authoritative sources.
