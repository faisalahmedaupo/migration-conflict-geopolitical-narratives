# Authoritative data sources

## UNHCR
Refugee Data Finder provides data on forcibly displaced and stateless populations and exposes an API for programmatic use.

## World Bank
World Development Indicators include international migrant stock indicators sourced from UN Population Division data.

## GDELT
GDELT provides global news/event data suitable for computational media analysis. Check current documentation before automated collection.

## ACLED
ACLED provides political violence and protest event data. Programmatic API access requires account authentication and must follow current terms.
