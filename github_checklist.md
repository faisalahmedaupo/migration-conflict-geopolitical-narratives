# GitHub / scholarship checklist

- [ ] Replace demo data with properly sourced real data.
- [ ] Add dataset citations and retrieval dates.
- [ ] Run tests.
- [ ] Add final figures with captions and source notes.
- [ ] Add paper PDF after the empirical study is complete.
- [ ] Add a `CITATION.cff` file.
- [ ] Add release tag (e.g. v2.0.0).
- [ ] Never commit API keys.
- [ ] Do not claim publication, peer review, or empirical findings unless true.
